# Mastercard 4853 Cardholder Dispute

Synthetic summary for demonstration. Not official Mastercard rule text.

## Overview

Reason code 4853 covers cardholder disputes such as goods or services not provided, not as described, defective merchandise, and credit not processed.

## Response window

The merchant has 45 calendar days from the chargeback date to submit a second presentment.

## Not as described

The cardholder must first attempt to resolve the issue with the merchant and must return or attempt to return the merchandise.

## Remedies

- Proof that the goods or services matched the description at the time of sale.
- Proof that a credit was already processed, with the credit date and amount.
- Evidence that the cardholder did not return the merchandise.
