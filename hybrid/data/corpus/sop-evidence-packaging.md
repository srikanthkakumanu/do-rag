# SOP Dispute Evidence Packaging

Internal operating procedure (synthetic example).

## File requirements

- Combine all evidence into a single PDF per dispute.
- Keep each PDF under 2 MB.
- Use the file name format CASEID_REASONCODE.pdf.

## Data protection

Never include full card numbers in evidence. An example of what not to paste is 4111 1111 1111 1111 or cardholder name: John Smith. Mask the card number to the last four digits.

## Cover letter

Every package starts with a one-page cover letter that lists the dispute reason code, the transaction date, the amount, and an index of attached exhibits.

## Quality review

A second analyst reviews every package above 500 USD before submission.
